# Local Web Chinese font and PDF icon
Based on upstream 4db6ac4ae2448df6389d8bb0bc54db6ba175721c. Changes are limited to allowed Hans faces in the Web font build, a pinned external Droid Sans Fallback Full build input, and the approved original PDF mark.
The Web build sets CRAFT_FONTS_DIR and CRAFT_FONTS_REQUIRED. The Droid font is Apache-2.0, pinned to AOSP commit 1aed5ea2dcf7cb0bf35635f378b2326461ba0df0 and verified against Git blob a9df00585a4e44cf91238b7b31385e7e36e1dea7 before embedding. Its SHA-256, source and NOTICE accompany the Web ZIP. No font binaries are committed. The existing font registration and language-change reset automatically retain the embedded Chinese face.
The glyph regression checks every Han character in both Chinese catalogs. The build also runs the real font build script with a wasm target to ensure Hans is embedded, and demonstrates its absence after reverting the Hans allowlist addition.
Original PDF icon assets replace the ArtCraft marks in Home/About and add a top-left PDF icon, browser favicon, Apple touch icon and relative standalone manifest. Upstream ArtCraft trademark artwork is removed from this modified version. Desktop packaging is not changed. Touch handling and language preferences remain upstream.
